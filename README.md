# Kalpana Chauhan Portfolio

Static portfolio site for Kalpana Chauhan, PR, events, and media.

## Local preview

Serve this directory with any static web server. For example:

```sh
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

The repository root is ready for deployment as a static site on Vercel. No build command is required; use `index.html` as the entry point.

The site is a static export. Some embedded WordPress-dependent behavior from the original export may not be available without a backend.
